# Digitization of Chemical Books Using Machine Vision

Исходники научной статьи «Оцифровка химических книг с использованием машинного зрения» / *«Digitization of Chemistry Books Using Machine Vision»*, подготавливаемой для журнала **«Современные технологии. Системный анализ. Моделирование»** (ИрГУПС).

Статья описывает конвейер оцифровки химической литературы: предобработку сканов, сегментацию страниц, распознавание текста (OCR) и химических структур (OCSR: MolScribe, DECIMER, Qwen3-VL), постобработку и приведение результатов к формату SMILES.

**Авторы:** Трофимов И. Л., Алакшин М. С., Рыбак А. В., Ткачёв Д. А.
(Иркутский государственный университет; ФИЦ «Иркутский институт химии им. А. Е. Фаворского СО РАН»)

## Структура репозитория

| Путь | Назначение |
|---|---|
| `main.tex` | Точка входа — модульная сборка, подключает всё через `\input{}` |

| `preamble.tex` / `user_preamble.tex` | Преамбула: пакеты, вёрстка (поля, две колонки, шрифт), кастомные команды (`\bicaption`, `\udc`, `\ruAbstract` и т. п.) |

| `chapter/` | Обёртки крупных разделов, подключают содержимое из `paragraph/` |
| `paragraph/` | Текст статьи по параграфам — основное место для правок |
| `table/` | Таблицы с результатами (`ocr.tex`, `ocsr.tex`) |

| `thebibliography_ru.tex` / `thebibliography_en.tex` | Список литературы по ГОСТ Р 7.0.100-2018, вручную через `\bibitem{}` (без BibTeX/Biber) |

| `NOTES.md` | Чек-лист требований журнала, план статьи, история правок |

## Сборка

Требуется дистрибутив TeX (MiKTeX/TeX Live) с движком `pdflatex`; библиография собирается вручную, отдельного прохода BibTeX/Biber не требуется.

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

или напрямую:

```bash
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex   # второй проход — для номеров ссылок/литературы
```

### Pre-commit hook

В репозитории настроен git-хук, который при каждом коммите пересобирает `main.pdf` и синхронизирует `monolith.tex`/`monolith.docx`. Включается один раз:

```bash
git config core.hooksPath .githooks
```

## Требования журнала (кратко)

- A4, поля 2.5 см сверху/снизу, 1.75 см слева/справа, Times New Roman 11 pt, одинарный интервал, две колонки по 8.5 см;
- резюме 180–250 слов и 5–10 ключевых слов на русском и английском;
- список литературы ≥ 18 источников по ГОСТ Р 7.0.100-2018, в порядке цитирования, без самоцитирования журнала;
- иллюстрации только чёрно-белые/оттенки серого, 300 dpi, `.jpg`/`.tif`;
- объём статьи 9–12 страниц.

Полный текст требований и статус их выполнения — в [`NOTES.md`](NOTES.md).
